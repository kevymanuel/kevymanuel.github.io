# kevymanuel.github.io

Portfolio site for Kevy Figuera, Senior Product Manager.

- `index.html` is the home page: positioning, selected work, how I work, experience, side project and contact.
- Each case study has its own page, such as `mandatory-handout-service.html`.
- `home.css` holds the shared design system. `case.css` adds the case study layout on top of it.
- `Kevy_Figuera_Resume.pdf` is the public resume, without a phone number.

Plain HTML and CSS, served by GitHub Pages from the `main` branch. No build step.
